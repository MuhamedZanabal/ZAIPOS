# Screenshots

Add application screenshots to this folder and update the paths in `README.md`.

Suggested screenshots:

- `dashboard.png` — Main dashboard with metrics and charts.
- `pos.png` — POS terminal with cart and payment.
- `inventory.png` — Inventory list or kardex view.
- `tables.png` — Table plan and KDS.
- `ai-agent.png` — WhatsApp AI agent conversation or settings.
- `reports.png` — Sales or inventory reports.

Use PNG or WebP formats and keep file sizes reasonable (under 300 KB each when possible).
