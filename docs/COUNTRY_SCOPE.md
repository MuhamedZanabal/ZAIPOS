# Country Scope

ZAIPOS is configured and documented for the Kingdom of Bahrain.

The active application baseline is Bahrain-first:

- English user-facing interface;
- BHD currency and three-decimal monetary formatting;
- Bahrain VAT defaults;
- +973 phone conventions;
- BenefitPay and Bahrain-relevant payment terminology;
- Talabat, WhatsApp and in-house delivery channel terminology;
- Bahrain-oriented sample data, addresses and operational examples.

Legacy country-specific behavior from the original upstream application is not part of the active product surface. Compatibility-only historical database values may remain solely where removing them would risk existing persisted data.
